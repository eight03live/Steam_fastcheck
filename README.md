# Steam Fast Check

## 概要

Steam Fast Check は、Steamストアの検索・確認作業を快適にするChrome拡張です。

検索結果のゲームにマウスを乗せたときの待ち時間をなくし、ユーザータグ、フレンドのウィッシュリスト人数、SteamDBの人気情報を一覧上で確認しやすくします。ゲーム詳細ページでは、Gemini APIを使って英語の説明を日本語へ翻訳できます。

対象ページの例: [Steamの近日登場ゲーム](https://store.steampowered.com/search/?filter=comingsoon&os=win)

## ダウンロードと導入手順

### Releasesから導入する

1. [最新リリースのページ](https://github.com/eight03live/Steam_fastcheck/releases/latest)を開きます。
2. ページ下部の「Assets」から `steam-fast-check-（バージョン）.zip` をダウンロードします。
3. ダウンロードしたZIPファイルを任意の場所へ展開します。
4. Chromeで `chrome://extensions/` を開きます。
5. 右上の「デベロッパー モード」を有効にします。
6. 「パッケージ化されていない拡張機能を読み込む」を選び、ZIPを展開したフォルダーを指定します。
7. 対象のSteamページを再読み込みします。

過去のバージョンを含む一覧は[Releases](https://github.com/eight03live/Steam_fastcheck/releases)から確認できます。

> [!NOTE]
> Chromeへ読み込んだ後も展開先のフォルダーを使用するため、フォルダーを削除・移動しないでください。更新時は新しいZIPを展開し、`chrome://extensions/` で拡張機能を再読み込みしてください。

### ソースコードから導入する

このリポジトリをクローンするか、GitHubの「Code」→「Download ZIP」からソースコードを取得します。ZIPの場合は展開し、上記と同じ手順でリポジトリのルートフォルダーをChromeへ読み込んでください。

```powershell
git clone https://github.com/eight03live/Steam_fastcheck.git
```

## 各種機能

### 近日登場ゲームをすぐに開く

設定画面上部の「近日登場チェック用ページ」ボタンから、所定の条件を指定したSteam検索ページを開けます。

### ホバー詳細とスクリーンショットの高速表示

- 詳細データの取得開始: 150ms（Steamの高速モードでは50ms）→ 0ms
- 詳細パネルの表示待機: 300ms（同100ms）→ 0ms
- 詳細パネルのフェード: 約200ms → 0ms
- ホバーパネルとスクリーンショットのフェードを無効化して即時表示
- スクリーンショットの切り替え間隔を0.1〜1.0秒の範囲で設定可能

「スクリーンショットの切り替え時間」は0.1秒刻みで選べます。変更は自動保存され、開いているSteam検索ページにも即時反映されます。初期値は0.6秒です。

初めて表示するゲームではSteamから詳細データを取得するため、回線やサーバーの応答に必要な時間は残ります。一度取得したゲームは即時に切り替わります。

### ユーザータグの常時表示と強調

検索行のプラットフォームアイコンを、先頭3件のユーザータグへ置き換えます。4件目以降は `+件数` にまとめ、すべてのタグ名をツールチップで確認できます。無限スクロールや検索条件の変更で後から追加された行にも自動で適用されます。

タグ名は検索結果に最初から含まれるタグIDを、同じページ内のローカライズ済みタグ名へ変換しているため、タグ表示のための追加通信は発生しません。

特定のタグを強調するには、Chromeのツールバーまたは拡張機能メニューから「Steam Fast Check」を開き、次のように設定します。

1. 「タグ名」にSteam上のユーザータグ名を入力します（完全一致、大文字と小文字は区別しません）。
2. カラーピッカーまたは `#RRGGBB` 形式で強調色を指定します。
3. 必要な数だけ「タグを追加」を押します。
4. 各行の左端にあるグリップをドラッグし、優先表示したい順番へ並べ替えます。
5. 「保存」を押します。

指定したタグは設定の上から順に検索行の先頭3タグへ優先表示され、ホバー詳細内の同じタグも同色で強調されます。設定変更は開いているSteam検索ページへ即時反映され、Chrome同期が有効なら他のChrome環境にも同期されます。

### フレンド人気度による枠色表示

ゲームをウィッシュリストに入れているフレンドの人数に応じて、検索行の枠色を変更します。

- 1人: 薄青 `#c9efff`
- 2人: 黄色 `#fff1a8`
- 3人: 赤 `#ffb8b8`
- 4人以上: 紫 `#e3bdff`

フレンド人数は初期の検索結果HTMLには含まれず、Steamのホバー詳細応答に含まれています。画面内と少し先にある行だけを最大4件ずつ先読みし、ホバーする前に枠色を適用します。

色は [src/friend-borders.css](src/friend-borders.css) 冒頭のCSS変数で変更できます。

### SteamDBフォロワー上位ゲームの強調

指定した年月に発売されるゲームのうち、SteamDBのフォロワー上位100件と一致するゲームへ金色の `TOP100` タグを表示します。照合にはゲーム名ではなくAppIDを使用します。

設定の「人気のゲームをハイライト」は、スイッチを切り替えた時点で保存されます。対象年月は開閉メニュー内の「対象年月を保存」で保存します。メニューを畳んだ状態でも、見出し右側で対象年月と取得済み件数を確認できます。

Steam検索ページを開くと、対象年月で絞り込んだSteamDBページを非アクティブな通常タブで1回読み込み、表示された一覧を取り込みます。取り込みに成功すると自動で開いたタブは閉じられ、無限スクロールで後から追加された検索行にも結果が適用されます。

ブラウザー確認が表示された場合はSteamDBタブが前面に移動するため、確認を完了してください。設定内の「SteamDBで対象一覧を開く」から手動で開いた場合も一覧を取り込めます。同じ年月の保存済み一覧がある場合は、新しい一覧を読み込んでいる間も以前の一覧を使用します。

`TOP100` の表示では、続けて優先度の高いユーザータグを2件表示し、残りを `+件数` にまとめます。タグ強調設定へ `TOP100` と入力すると、色と表示順を変更できます。4番目以降へ並べても `TOP100` は3つの表示枠内に残ります。未設定時は金色で先頭に表示されます。

見た目は [src/search-tags.css](src/search-tags.css) の `.steam_fast_check_popular_tag` で変更できます。

### 新しいタブでゲームページを開く

検索結果を通常クリックすると、元のリスト位置を保ったままゲームページを新しいタブで開きます。設定の「ゲームを新しいタブで開く」をオフにして保存すると、Steam標準どおり現在のタブで開きます。初期値はオンです。

### 検索結果の件数区切り

無限スクロールで追加される検索結果へ、100件ごとに件数付きの区切り線を表示します。

### Geminiによるゲーム説明の翻訳

設定の「ゲーム説明をGeminiで翻訳」をオンにすると、ゲーム詳細ページにある次の2箇所を英語から日本語へ翻訳します。スイッチの変更は保存ボタンを押さなくても即時反映されます。

- 上部の短い説明（`.game_description_snippet`）
- 「About This Game」（`#game_area_description`）

翻訳された文章をクリックすると英語の原文へ切り替わり、もう一度クリックすると日本語訳へ戻ります。ドラッグによる文字選択では切り替わらないため、どちらの文章もコピーできます。

APIキーとモデルは「Gemini API設定」を開き、欄内の「API設定を保存」で保存します。下部にあるタグ設定用の「保存」とは別です。APIキーを入力して「モデル一覧を更新」を押すと、Geminiの `models.list` APIから `generateContent` 対応のテキストモデルを取得して選択できます。「接続テスト」では短い文章を実際に1件翻訳します。

APIキーはChrome同期を使わず、この端末の拡張機能用ローカルストレージに保存されます。ゲームページのスクリプトから読めないようアクセスを制限し、Gemini APIとの通信は拡張機能のバックグラウンドで行います。ただし、OSの暗号化された資格情報ストアへ保存する方式ではありません。

翻訳対象の説明文はGoogle Gemini APIへ送信されます。APIの契約、無料枠、利用量によって料金が発生する場合があります。同じモデルと説明文の翻訳結果は最大60件までローカルにキャッシュされ、「翻訳キャッシュを消去」から削除できます。

## 対象サイトと権限

- 検索支援: `store.steampowered.com/search/`
- Gemini翻訳: `store.steampowered.com/app/`
- 人気ゲームの照合: `steamdb.info`
- Gemini API: `generativelanguage.googleapis.com`

人気ゲームの照合にはSteamDB、説明文の翻訳にはGoogle Gemini APIへの通信権限を使用します。
