# Steam Fast Check

Steamストアの検索結果で、ゲーム行にマウスを乗せてから詳細パネルが表示されるまでの意図的な待機時間を取り除き、ユーザータグの常時表示、スクリーンショットの高速切り替え、フレンド人気度による枠色表示、SteamDBフォロワー上位ゲームの強調を行うChrome拡張です。

対象ページの例:

<https://store.steampowered.com/search/?filter=comingsoon&os=win>

## 変更内容

- 設定画面上部の「近日登場チェック用ページ」ボタンから所定の検索条件を開く
- 詳細データの取得開始: 150ms（Steamの高速モードでは50ms）→ 0ms
- 詳細パネルの表示待機: 300ms（同100ms）→ 0ms
- 詳細パネルのフェード: 約200ms → 0ms
- スクリーンショットの切り替え: 1秒ごと → 0.5秒ごと
- ホバーパネルとスクリーンショットのフェードを無効化し、即時表示
- 検索行のプラットフォームアイコンを先頭3件のユーザータグへ置換
- 4件目以降は `+件数` で表示し、全タグ名をツールチップに表示
- 指定年月に発売されるゲームのうち、SteamDBのフォロワー上位100件と一致する検索行のタグ列先頭に `TOP100` を表示
- 検索結果を通常クリックしたとき、元のリスト位置を保ったままゲームページを新しいタブで開く（設定で無効化可能）
- 無限スクロールの検索結果へ100件ごとに件数付きの区切り線を表示
- Gemini APIを使い、英語だけのゲーム説明を日本語へ翻訳（設定で有効化）

ユーザータグは検索結果に最初から含まれるタグIDを、同じページにあるローカライズ済みのタグ名へ変換しています。追加通信は発生しません。無限スクロールや検索条件の変更で後から追加された行にも自動適用されます。

### フレンドのウィッシュリスト人数

フレンド人数は初期の検索結果HTMLには含まれず、Steamのホバー詳細応答に含まれています。画面内と少し先にある行だけを最大4件ずつ先読みして、ホバー前に次の枠色を適用します。

- 1人: 薄青 `#c9efff`
- 2人: 黄色 `#fff1a8`
- 3人: 赤 `#ffb8b8`
- 4人以上: 紫 `#e3bdff`

色は [src/friend-borders.css](src/friend-borders.css) 冒頭のCSS変数で変更できます。

### SteamDBフォロワー上位ゲームの強調

設定の「人気のゲームをハイライト」はスイッチを切り替えた時点で保存されます。対象年月は開閉メニュー内の「対象年月を保存」で保存します。開閉メニューを畳んだ状態でも、見出し右側に対象年月と取得済み件数を表示します。Steam検索ページを開いた時に、その年月を発売日とするゲームだけに絞ったSteamDBページを通常の非アクティブタブで1回読み込み、画面に表示されたフォロワー上位100件のAppIDと一致するゲームのタグ列先頭へ金色の `TOP100` タグを付けます。表示幅を保つため、該当行では `TOP100` に続いて優先度の高いユーザータグを2件表示し、残りは `+件数` へまとめます。取り込みに成功すると、拡張が自動で開いたSteamDBタブは閉じます。無限スクロールで後から追加された行にも適用されます。

バックグラウンド通信はSteamDBのブラウザー確認に振り分けられるため使用しません。自動で開いた通常タブにブラウザー確認が表示された場合は、そのタブを前面に出すので確認を完了してください。ページ本体が表示されると一覧が自動で取り込まれ、開いているSteam検索ページへ反映されます。設定内の「SteamDBで対象一覧を開く」から手動で対象ページを開いた場合も、表示された一覧を取り込みます。同じ年月で以前に取得できた一覧がある場合は、新しい一覧の読み込み中も保存済み一覧を使用します。

照合にはゲーム名ではなくAppIDを使います。`TOP100` タグの見た目は [src/search-tags.css](src/search-tags.css) の `.steam_fast_check_popular_tag` で変更できます。

タグ強調設定へ `TOP100` と入力すると、通常のユーザータグと同じカラーピッカーで色を変更でき、ドラッグした順序も検索行へ反映されます。設定がない場合は金色・先頭表示です。表示順を4番目以降にした場合でも、`TOP100` は隠さず3つの表示枠内へ残し、その分のユーザータグを `+件数` へまとめます。

### ユーザータグの強調設定

Chromeのツールバーまたは拡張機能メニューから「Steam Fast Check」のアイコンをクリックすると設定が開きます。

「ゲームを新しいタブで開く」をオフにして保存すると、Steam標準どおり現在のタブでゲームページを開きます。初期値はオンです。

1. 「タグ名」にSteam上のユーザータグ名を入力します（完全一致、大文字小文字は区別しません）。
2. カラーピッカーまたは `#RRGGBB` 形式で強調色を指定します。
3. 必要な数だけ「タグを追加」を押します。
4. 各行の左端にあるグリップをドラッグして、優先表示したい順番へ並べ替えます。
5. 「保存」を押します。

指定したタグは設定の上から順に検索行の先頭3タグへ優先表示され、ホバー詳細内の同じタグも同色で強調されます。設定変更は開いているSteam検索ページへ即時反映され、Chrome同期が有効なら他のChrome環境にも同期されます。

初めて表示するゲームではSteamから詳細データを取得するため、回線やサーバー応答に必要な時間は残ります。一度取得済みのゲームは即時に切り替わります。

### Geminiによるゲーム説明の翻訳

設定にある「ゲーム説明をGeminiで翻訳」のスイッチをオンにすると、保存ボタンを押さずに即時反映され、ゲーム詳細ページにある次の2箇所だけを英語から日本語へ翻訳します。APIキーやモデルは「Gemini API設定」を開き、欄内の「API設定を保存」で保存します。下部のタグ設定用「保存」とは別です。

- 上部の短い説明（`.game_description_snippet`）
- 「About This Game」（`#game_area_description`）

翻訳後の文章をクリックすると、その文章自体が英語の原文へ切り替わります。もう一度クリックすると日本語訳へ戻ります。ドラッグによる文字選択では切り替わらないため、原文・翻訳文ともコピーできます。

Gemini APIキーを入力して「モデル一覧を更新」を押すと、Geminiの `models.list` APIから現在利用できるモデルを取得し、`generateContent` に対応するテキストモデルを選択できます。「接続テスト」では短い文章を実際に1件翻訳します。

APIキーはChrome同期を使わず、この端末の拡張機能用ローカルストレージへ保存します。ゲームページのスクリプトからは読めないようアクセスを制限し、Gemini APIとの通信は拡張機能のバックグラウンドで行います。ただし、OSの暗号化された資格情報ストアへ保存する方式ではありません。

翻訳対象の説明文はGoogle Gemini APIへ送信されます。APIの契約・無料枠・利用量によって料金が発生する場合があります。同じモデルと同じ説明文の結果は最大60件までローカルにキャッシュし、「翻訳キャッシュを消去」から削除できます。

## Chromeへの読み込み方

1. Chromeで `chrome://extensions/` を開きます。
2. 右上の「デベロッパー モード」を有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」を選びます。
4. このフォルダー（`Steam_fastcheck`）を選択します。
5. 対象のSteam検索ページを再読み込みします。

検索支援は `store.steampowered.com/search/`、Gemini翻訳は `store.steampowered.com/app/` で動作します。人気ゲームの照合には `steamdb.info`、Gemini翻訳には `generativelanguage.googleapis.com` への通信権限を要求します。
